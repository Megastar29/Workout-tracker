# Трекер тренувань
Трекер тренувань - це сайт, який створюється в рамках лабораторних робіт із програмування вебзастосувань.

## Аудит безпеки застосунку

### 1. Захист від XSS
* Аудит коду: Перевірено всі виклики innerHTML у файлі `script.js`. Усі знайдені входження слугують виключно технічним скиданням вмісту (`element.innerHTML = ""`) перед формуванням нового інтерфейсу.
* Моделювання вразливості: У полі типу тренування форми та при виведенні заголовка картки протестовано введення `<img src=x onerror="alert('XSS')">`. При використанні innerHTML відбувалося виконання скрипту.
* Виправлення: Усі динамічні дані користувача та журналу тренувань генеруються за допомогою безпечного DOM API (`document.createElement()`) і виводяться через властивість .textContent. Будь-які HTML-теги автоматично екрануються браузером і інтерпретуються як звичайний текст. У формі додатково застосовано обмеження введення за допомогою списку `<select>`.

### 2. Аудит сховищ localStorage та IndexedDB
* Аналіз даних: У сховищах `localStorage` та `IndexedDB` зберігаються виключно знеособлені метрики журналу занять: `id`, `type`, `duration`, `date`.
* Висновок: Застосунок не зберігає паролів, токенів автентифікації чи персональних конфіденційних даних. Структура сховища повністю відповідає вимогам безпеки.

### 3. Перевірка на відсутність секретів та API-ключів
* У вихідному коді проєкту (`script.js`, `index.html`) відсутні захардкоджені паролі, приватні сертифікати або конфіденційні токени.
* Константи `dbName`, `dbVersion`, `storage_key` є відкритими локальними ідентифікаторами браузерного API.
* Оскільки архітектура застосунку повністю автономна і базується на клієнтській базі IndexedDB, звернення до зовнішніх хмарних API не виконується, тому зовнішні ключі доступу не потрібні.

### 4. Мережева безпека (HTTPS)
* Застосунок розгорнуто як статичний SPA на платформі GitHub Pages.
* Хостинг примусово забезпечує з'єднання через захищений протокол HTTPS із шифруванням SSL/TLS, що захищає користувацький трафік від перехоплення та підміни даних.
